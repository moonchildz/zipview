# 집과 전망 (ZipView)

**전국의 집을 주소·동·호로 찾아, 원본 평면도와 실내 구조를 확인하고 각 창에서의 주변 전망을 살펴보는 것**을 목표로 하는 프로젝트다. 현재는 공동주택 자료를 중심으로 수집·연결·모델링을 진행한다.

신촌푸르지오, 경희궁자이, 한신한진은 세대 연결과 실내·전망 표현을 검토하는 시범 대상이다. 프로젝트의 지원 대상을 이 단지들로 한정하지 않는다. 기본 화면도 특정 단지 데모가 아닌 주소 조회다.

## 현재 어디까지 되는가

2026-11-08 로컬 확인 기준. 아래는 보존된 2026-09-24~25 작업 결과이며, 전국의 모든 집에 정확한 실내·전망이 구현됐다는 뜻은 아니다.

| 단계 | 확인한 자료·결과 | 의미와 한계 |
| --- | ---: | --- |
| 전국 공동주택 동·호수 색인 | 15,580,435개 원본 행 | 2025년 공동주택 공시가격 원본 조회. 현재의 모든 주택을 포함하는 목록은 아님 |
| 공식 원본의 호수·면적과 평면도 이미지 연결 | 426,416행 | 평면도 후보가 연결된 원본 행. 방향·반전·창 위치·조망 검증과는 별도 |
| 공급자 자료상 전체 호수에 평면도 이미지 연결 | 296개 단지·249,594세대 | 해당 공급자 목록 기준의 제작 우선 후보. 실제 모든 세대의 도면·치수가 검증된 수치는 아님 |
| 평면 외곽·벽선 벡터 초안 | 4,810개 이미지 변형 | 기본형·확장형 등을 포함한 자동 초안. 완성된 실내 3D 모델 수가 아님 |
| 단지별 제작 작업 묶음 | 1,917개 단지 | 우선 제작 296개, 부분 제작 584개, 평면 이미지 확보 필요 1,037개 |
| 지형·층 높이를 적용한 외부 전망 시범 | 1,658세대 | 신촌 2단지·경희궁자이 2단지·한신한진 205동. 실제 창 위치와 층고는 추정이 포함됨 |

전국 색인에서 평면도 이미지 후보가 연결된 행은 약 **2.74%**이며, 나머지 **15,154,019행**에는 이 조건을 충족하는 후보가 없다. 이 색인의 이미지 연결 후보는 현재 서울에 집중되어 있고, **경기도는 동·호수 원본은 색인되어 있으나 이미지 후보 연결은 0행**이다. 보존된 공공 원본을 더 판독·연결하면 수치는 달라질 수 있다.

전국 동·호수 조회 DB, 기본 웹 앱의 카탈로그, 모델 작업 DB는 별도 산출물이다. 수집한 자료나 생성한 초안 전체가 기본 앱의 실내·전망 화면에 통합된 상태는 아니다. `build:linkage`도 전국 DB나 모델 초안을 모두 완성된 화면으로 바꾸는 명령은 아니다.

집계 근거와 정의: [전국 동·호수 색인](research/NATIONAL-UNIT-REGISTRY.md), [자료 보유 점검](research/MATERIAL-READINESS-AUDIT.md), [모델 일괄 제작](research/APARTMENT-MODEL-WORK.md), [시범 세대 연결·전망 진행](research/linkage/TARGET-PROGRESS.md).

## 실행과 조회

Node.js 환경에서 프로젝트 루트의 명령을 실행한다.

```powershell
npm install
npm run dev
```

`dev`와 `build` 전에 `build:linkage`가 실행되어 현재 PC에 저장된 자료로 기본 앱의 카탈로그를 재생성한다.

| 화면 | 경로·명령 | 제공 범위 |
| --- | --- | --- |
| 주소·동·호 조회 | `/` 또는 `/?site=catalog` | 등록 주소 검색, 보유 원본 평면도, 세대 연결 근거와 누락 표시 |
| 전국 동·호수 조회 | `npm run units:serve` → `http://127.0.0.1:5183/` | 전국 SQLite 색인 검색, 동·호수와 평면도 후보 연결 조회 |
| 모델 제작 현황 | `/research/linkage/generated/apartment-model-work/review.html` | 단지·타입별 초안과 남은 작업 조회 |
| 평면도 후보 검토 기록 | `/research/linkage/generated/usable-plan-candidates/review.html` | 기존 후보 목록과 대표 이미지 검토. 제작 현황은 위 별도 화면 참조 |
| 신촌푸르지오 시범 | `/?site=sinchon` | 지원 도면의 실내 초안·창 선택, 층별 전망 비교 |
| 경희궁자이 시범 | `/?site=xi` | 지원 세대의 실내·창·층 선택과 전망 비교 |

전국 조회와 모델 작업 명령은 Python을 사용한다. 현재 `package.json`의 해당 명령은 `.tools/aerial-python/Scripts/python.exe`를 참조한다. 다른 환경에서는 Python과 필요한 패키지를 준비하고 경로를 맞춰야 한다. 전국 조회 DB가 없다면 원본을 준비한 뒤 `npm run units:build`가 필요하다. 자세한 복원·실행 방법은 각 작업 문서를 따른다.

원본 다운로드, 캐시, 생성 DB와 검토 페이지는 대부분 Git 제외 대상이다. **저장소를 복제하는 것만으로 이 PC의 전국 색인과 수집 자료가 함께 내려오지는 않는다.**

## 자료 수집과 모델링

주소·평면도 연결은 공통 파이프라인으로 처리한다. 특정 단지의 UI에 세대별 분기를 계속 추가하는 방식으로 지원 범위를 넓히지 않는다.

```powershell
# 주소에서 자료 수집 후 기본 앱 카탈로그 갱신
npm run pipeline:addresses -- "서울 종로구 송월길 99"
npm run pipeline:addresses -- --file research/linkage/addresses.example.json

# 이미 저장한 자료로 기본 앱 카탈로그만 갱신
npm run build:linkage

# 확보 자료로 제작 작업 준비·평면 초안 생성·동 배치 후보 연결
npm run models:prepare
npm run models:run
npm run models:sites
npm run models:status
```

주소 수집기는 공개 공급자의 단지·평형·동호수 자료를 읽고 출처·캐시·실패 단계를 보존한다. 공개 구조화 자료가 없는 호수나 타입을 임의로 생성하지 않는다. 새 주소의 실시간 수집에는 개발/로컬 preview 서버가 필요하며, 정적 파일 배포만으로는 실행되지 않는다. [주소 연결 파이프라인과 명령](research/linkage/README.md).

공공·공식 원본은 **SH·LH·건설사·시행사·공공기관에서 직접 수집**한다. CAD만 고르지 않고 PDF·이미지·압축파일 등 공개 원본을 폭넓게 보존한 뒤 내용 판독과 모델링 가능성을 평가한다. KOVI와 아키스케치는 수집원에서 제외한다. 기존 공급자 연결 자료와 공식 원본의 연결 근거는 별도로 기록한다. [다운로드 자료 연결 결과](research/DOWNLOADED-MATERIAL-CONNECTION-RESULTS.md).

## 모든 집으로 확장하기 위해 남은 작업

- 전국 동·호수 목록에 평면도·배치도·타입별 치수와 층별 예외를 연결한다. 같은 면적만으로 세부 타입을 확정하지 않는다.
- 동 번호와 실제 지도 건물을 대응시키고, 세대별 회전·좌우 반전·창 개구부·층고·바닥 표고를 검증한다. 자동 벡터 초안과 검증된 모델을 구분한다.
- 지역별 주변 환경을 공유하고 각 집·창의 카메라를 연결한다. 이 공통 장면으로의 실내·전망 통합은 진행 중이다.
- 최신 신축과 원본 누락 주택을 추가하고, 실제 도면·현장 자료로 모델과 전망의 일치를 확인한다.

주변 환경은 건물·나무·낮은 식생·도로를 우선 구현하고 물 영역을 추가한다. 수치지도는 **1:1,000만** 사용하며 다른 축척으로 대체하지 않는다. 수집 순서는 서울 이후 **경기도 전역**, 이후 다른 지역이다. 진행 중인 서울 위성 다운로드는 보존하고, 추가 위성 획득은 전국 지도·지리 데이터 수집·검증 뒤에 진행한다. 미제공·미검증 지역은 공백으로 남긴다. [전국 수집 계획](research/NATIONAL-COLLECTION-PLAN.md), [주변 환경 구현 기준](research/ENVIRONMENT-IMPLEMENTATION.md).
