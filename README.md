# 집과 전망: 신촌푸르지오 PoC

주소/동/호를 분양 당시 타입 자료에 연결하고, 원본 평면도 및 3D 구조 초안을 보여주는 로컬 웹 앱.

## 실행

Node.js 환경에서 `npm install`, `npm run dev`.

현재 PC에는 작업 폴더의 `.tools/node-v24.21.0-win-x64`에 포터블 Node.js를 준비했다. PowerShell에서:

```powershell
$env:Path = (Join-Path (Get-Location) '.tools\node-v24.21.0-win-x64') + ';' + $env:Path
npm.cmd run dev
```

## 범위

- 원본 평면도 8종(59D 기본형 추가), 단지 배치도/동호수 배치표, 분양 조감도.
- 주소/동/호 조회는 판독한 22개 세대에 한정. 예: 204동 802호(84E), 201동 1404호(84A).
- 59D/84A/84E의 3D 벽/창호 초안, 회전/확대, 방별 내부 시점, 화면 저장.
- 다른 타입은 원본 평면도 열람 가능. 아직 벡터화하지 않은 타입에 대체 3D 모델을 사용하지 않는다.
- 미등록 세대는 오류를 표시하고 세대 연결을 해제한다. 임의 타입을 추정하지 않는다.
- 206동 504호/1004호를 별도의 추정 시나리오로 추가. 첫 화면에서 같은 창 좌표의 5층/10층 전망을 비교한다. 호수의 존재 및 정확한 창 위치를 확인한 결과는 아니다.
- 주변 OSM 건물 외곽 2,716개와 Mapzen Terrain 지형을 로컬 스냅샷으로 렌더링. 206동 높이 태그는 50m/17층, 지반 표고는 저해상도 DEM에서 약 51.19m로 추정.
- 방위/시야각/층 선택, 동기 회전, 층고/지반/창 좌표 보정, 높이 가정 건물 표시 여부를 조절한다. 기본 층고 2.9m, 눈높이 1.5m이며 5층/10층 차이는 14.5m. 전망 눈높이는 0.8~2m 범위에서 조절할 수 있다. 실내 뷰 기본 눈높이도 1.5m다.
- 도로/보행로 1,595개 구간을 폭이 있는 면으로 렌더링한다. 폭 정보가 없어 차로 수 또는 도로 종류에 따라 폭을 추정한다. 교량/터널/면형 도로 등 지원하지 않는 36개 구간은 생략한다. 근거리 225개 건물에 추정 창호/하부 마감을 추가했다. 도로와 추정 외관을 각각 숨길 수 있다.
- 화면의 건물 이름과 클릭 조회, 주변 500m 배치 대조 지도를 추가했다. OSM 건물 이름이 없는 경우 ID와 이름 미확인을 표시한다. 숫자 동 이름에 붙인 단지명은 OSM 부지 외곽 포함 관계에 따른 추정이며 실제 동 식별 검증은 아니다. 건물 높이 근거와 원본 OSM 링크를 함께 표시한다.
- 도로 구간 선택, 해당 방향 내려다보기, 현재 모델의 최근접 도로점 가림 판정, 위성지도/Street View 링크를 제공한다. Google Earth용 KML에는 현재 두 층의 카메라와 OSM 건물 외곽/도로 중심선을 내보낸다. Google 실사 3D API는 연결하지 않았으며 Earth에서 실제 로딩/정합은 미검증이다.
- 방향 검토 후 기존 동향 78도 시점을 폐기하고 206동 남동쪽 외벽 후보로 이동했다. 해당 지도 외곽선에 수직인 약 123도를 기본값으로 사용한다. 창의 정확한 위치나 실측 방위가 확인된 것은 아니다. 원본 배치도와 지도 좌표 시선도를 전망 아래에 표시하고 회전에 동기화한다.
- 남산타워, 롯데월드타워, 63빌딩, 파크원 2개 동, IFC 3개 동, 콘래드 서울, 서울스퀘어 등 주요 랜드마크 10개를 좌표/높이 자료에 따라 추가했다. 선택하면 같은 창 위치에서 해당 방향으로 회전하며, 표시 여부와 출처를 확인할 수 있다.
- 실제 촬영 전망이 아니다. 일반 건물 범위 약 2km, 지형 범위 32km. 주요 랜드마크 외 원거리 일반 건물/수목/실제 외벽/창틀은 미반영. 가림 표시는 현재 모델의 랜드마크 상단 한 점에 대한 판정으로 실제 조망을 보증하지 않는다. 창의 실제 방향 및 실내 모델과 지리 좌표의 정합은 미검증.
- 3D는 이미지 수동 판독 초안. 59D는 표기 치수 9.4m 폭으로 축척을 잡았고 높이는 추정. 실측 모델이나 준공 상태가 아니며, 현 세대의 일치 여부는 미확인.

도면 출처와 상세 한계: [수집 기록](research/sinchon-prugio/README.md).

## 검증

`npm test`, `npm run build`. 개발 서버 실행 후 `npm run verify:browser` (로컬 Chrome 필요).

브라우저 검증은 데스크톱/모바일 스크린샷, 캔버스 픽셀, 확대/방 시점/세대 변경, 오류 처리, 원본 이미지 로딩, 가로 넘침을 확인한다. 이는 앱 동작 검증이며 건축적 정확도 검증은 아니다.

## 다음 데이터 단계

Google/Kakao 조회 가능성 및 실제 인증 오류 기록: [지도 제공자 검토](research/sinchon-prugio/map-provider-review.md).
로컬 `.env.local`에 키를 설정하면 `npm run probe:maps -- --provider google` 또는 `--provider kakao`로 210동 후보를 1회 조회한다. 키가 없으면 요청하지 않는다. 조회는 진단용이며 결과를 저장하거나 기존 3D 모델에 반영하지 않는다.

1. 원본 도면/준공 자료로 동호 매핑 범위를 확대하고 치수를 보정한다.
2. 세대별 반전과 회전을 확인하고 내부 좌표를 지리 좌표에 연결한다.
3. 주변 건물/지형 데이터와 실제 세대 촬영 사진으로 전망을 대조한다.
