# Project decisions

- User requirement (2026-09-20): collect publicly released apartment source materials directly from SH, LH, construction companies, developers and public agencies. Exclude KOVI and Archisketch as acquisition sources. Prioritize broad original-file preservation (CAD, PDF, images and archives), with modeling and usability assessment afterward; do not filter collection to already usable CAD only.

- User requirement (2026-09-18): numerical/topographic maps must **always be 1:1,000**. Never collect, use, or automatically substitute 1:5,000 or any other scale. Record unavailable 1:1,000 coverage as a gap.
- User priority (2026-09-19): **all of Gyeonggi-do is mandatory**. Collect Gyeonggi-do immediately after Seoul and before Busan/other metropolitan areas; do not restrict it to selected apartment locations.
- Preserve the currently running Seoul satellite download. After that queue finishes, prioritize nationwide 1:1,000 map/geographic data collection and verification. All further satellite acquisition (including remote catalogue/preview work) comes last, after the nationwide map stage. Offline target preparation is allowed earlier.
- These requirements override older national-collection plans. Keep executable configuration and queued jobs consistent with them. See `research/NATIONAL-COLLECTION-PLAN.md` and `research/ENVIRONMENT-IMPLEMENTATION.md`.
