# 한신한진 205동 지형·높이 적용

`npm run pipeline:elevations`가 원자료 확인, 지형 변환, 실제 동·호 연결과 전수 검사를 수행한다.

- 주소: 서울특별시 성북구 성북로4길 52, 돈암동 609-1.
- 건물: [OSM way 559970274](https://www.openstreetmap.org/way/559970274). `205동`, 지상21층,84세대 태그를 건축물대장 `100915676`의 동일 이름·주소·층수·세대수와 대조했다. 외곽 형상 자체는 OSM 추정이다.
- 건축물대장: [건축물 생애이력 관리시스템](https://www.hub.go.kr/portal/gis/bld/idx-bld-list.do)의 공개 검색·상세 화면. 높이는 비어 있으므로 **21×2.9=60.9m를 추정**했다. 층별 면적을 층고로 해석하지 않는다.
- 실제 세대: [국토교통부 주택 공시가격 정보](https://www.data.go.kr/data/3073746/fileData.do)2025년 전체 CSV를 다시 추출했다.205동101~2104호의84개 실제 행을 연결하며 모두 전용132.96㎡다. 호수를 범위 생성으로 만들어 넣지 않는다.
- 타입: [KB 한신·한진36331](https://kbland.kr/se/c/36331)의 유일한132.96㎡ 타입에 연결했다. 공급164.28㎡, 약49.7평. 해당 공급자 응답에는 원본 평면도 이미지가 없었다. SH 임대32㎡ 도면은 이 동에 적용하지 않는다.
- 지반: 기존 신촌 지역의32km Mapzen DEM을 경위도로 재투영·보간했다.205동 중심 `[127.010049475,37.59535095]`의 지반 추정값은131.44160367885695m다. 새 지형 격자는20km 범위,62.5m 간격이며 원래 격자 범위를 벗어나면 생성에 실패한다. 실제1층 마감 바닥이나 필로티·단차의 실측값은 아니다.
- 시점: 지반+(층−1)×2.9m+눈높이1.5m. 원본 건물 외곽의 넓은 외벽에서 방위를 계산하고 호 라인을 등간격으로 배치하는 **미검증 후보**다. 실제 거실 창 위치·반전이 확정됐다는 뜻이 아니다.
- 주변: 한신한진 부근1091개 OSM 원소를 공개 Overpass에서 수집하여 기존 주변 환경과 합쳤다. 결과는건물3272개,도로2149개이며 원거리 일반 건물 전수 자료는 아니다.

원자료는 `research/linkage/downloads/hanshin-hanjin/`, 변환 결과는 `scene.json`, 세대별 계산은 `research/linkage/generated/catalog.json`에 저장된다. `source.osmSha256`과 원래주택 CSV 해시로 원자료를 추적한다. 생성 스크립트는 `scripts/prepare-hanshin.mjs`, 연결 스크립트는 `scripts/connect-hanshin.mjs`다.
