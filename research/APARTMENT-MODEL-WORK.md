# 아파트 모델 일괄 제작

`scripts/apartment-model-work.py`는 확보한 평면도와 동호수 자료를 실제 제작 작업으로 전환한다. 경희궁자이·신촌푸르지오에서 사용한 순서처럼 평면 초안, 동·호 라인 스택, 단지 작업 묶음을 만든다. 원본 자료가 부족해도 작업을 중단하지 않고 추론 결과와 미확정 항목을 함께 보존한다.

## 현재 작업 범위

- 우선 제작 296개: 공급자 기준 모든 타입 이미지와 전체 동호수 연결이 있는 단지
- 부분 제작 584개: 확보된 타입은 먼저 처리하고 누락 타입은 별도 확보 작업으로 유지
- 원본 확보 1,037개: 현재 공개 평면 이미지가 없는 단지
- 타입 이미지 변형 4,810개를 디코딩하여 평면 외곽과 벽선 후보를 만든다.
- 전체 1,917개 단지의 동·호 번호를 건물/라인/층 스택으로 정리한다.

## 실행

```powershell
npm run models:prepare
npm run models:run
npm run models:sites
npm run models:status
```

상태는 `research/linkage/generated/apartment-model-work/progress.json`, 작업 DB는 `work.sqlite`, 검토 화면은 `review.html`이다. `worker.lock`이 있으면 같은 작업자를 중복 실행하지 않는다. 원본 파일은 수정하지 않는다.

## 초안에 포함되는 것

- 타입, 기본형/확장형, 원본 파일과 해시
- 전용면적을 검출된 평면 외곽 면적에 대응시킨 잠정 축척
- 평면 외곽 다각형과 주요 벽선 후보
- 동별 호 라인, 적용 타입의 다수값, 층별 예외
- 1:1,000 지도·지형, 영상, OSM 및 공개 배치도 문서 후보
- 누락 평면도, 배치도, 높이, 동호수 충돌을 위한 후속 작업

자동 초안은 회전, 좌우반전, 실제 창 개구부와 창턱, 공용 코어, 준공 변경, 층고를 확정하지 않는다. 이 값들은 `null` 또는 남은 작업으로 둔다. 초안 생성은 모델 제작의 시작이며 검증 완료나 출시 가능 판정이 아니다.

2026-09-24 실행에서 관련 1:1,000 도엽 1,909개를 검사했다. 1,873개 단지에서 도로명주소가 같은 건물 외곽과 층수 후보를 찾았고, 그중 1,659개는 수치지도의 명칭·주기에서 공급자 동 번호와 같은 동을 하나 이상 찾았다. 같은 주소의 다른 차수·상가·부속동이 섞일 수 있으므로 주소 일치 외곽은 후보 상태로 유지한다. 층수에서 계산한 높이는 `층수 × 2.9m` 가정이다.
