# 아파트 CAD·구조화 평면도 공급 경로 조사

확인일: 2026-09-20. 목적: 서울·경기도 아파트의 벽·문·창 형상을 자체 모델링에 사용할 수 있는 파일 또는 데이터로 확보하기.

## 사용자 방향 재확인

2026-09-20: KOVI·아키스케치 같은 가공 데이터 판매처보다, 공개된 원본 DWG/DXF 등을 직접 확보하는 공급원을 찾는 것이 목적이다. 업체 구매를 기본 경로로 추진하지 않는다.

SH 중간 집계: 조사 시점 1,981개 저장 manifest 중 type-plan 첨부가 있는 대상은 526개, DWG/DXF를 확보한 대상은 1개였다. type-plan은 서버 분류이며 실제 평면도 내용·타입 완전성 검증과 다르다. 전체 4,248개 검색 대상에는 비아파트 주택도 포함되어 전국 아파트 단지 수와 직접 나누어 커버리지를 계산하면 안 된다.

업체의 원본 확보 방식에 대한 추가 근거:

- 아키스케치는 건설사 홈페이지의 평면도를 확보해 2018년부터 3D화했으며, 이후 이미지에서 치수와 구성 요소를 인식하는 시스템을 개발했다고 설명한다. DXF만 수집해 재판매한다는 근거는 없다. https://www.archisketch.com/ko/blog/63be6c2cb366a10011c064a5
- KOVI 제작 요청 페이지는 네이버 부동산 단지 정보를 기반으로 제작하며 이미지가 없는 경우 도면 이미지 첨부를 요구한다. 이것으로 전체 DB 제작 방식이나 원본 CAD 보유 여부를 단정할 수 없다. https://kovi.com/CustomerSupport/AptRequestWrite

## 결론

- 실제 공개 DWG 파일을 SH 자료에서 1개 다운로드하고 파일 헤더를 확인했다. 내부 도형·치수는 아직 검증하지 않았다.
- 대량 공급 의사를 가장 명확히 밝힌 곳은 KOVI다. 공급 파일 형식과 지역별 목록은 공개 페이지에서 확인되지 않았다.
- 아키스케치는 DXF 및 GLB 등 외부 파일 내보내기를 명시한다. 기존 아파트 도면 라이브러리에 대한 대량 반출·사용 조건은 미확인이다.
- 서울·경기도 전체를 제공하는 무료 CAD 저장소 또는 벽·문·창 좌표 JSON 공개 다운로드는 이번 조사에서 확인하지 못했다. 존재하지 않는다는 뜻은 아니다.

## 1. KOVI / 한국가상현실: 대량 데이터 공급 후보

공식 출처: https://corp.kovi.com/platform/p_koviapt.html

공식 안내는 14만 개 이상의 2D/3D 아파트 데이터를 API 연동 또는 대량 구매로 제공한다고 밝힌다. 이 수치는 업체가 제시한 데이터 수이며 단지 수가 아니다. DWG/DXF/JSON 등 구체적인 납품 형식, 벽·개구부 좌표 제공 여부, 서울·경기도별 보유 목록과 가격은 확인하지 못했다.

판단: 대량 확보를 위한 우선 검토 대상. API라는 명칭만으로 원시 형상 데이터를 제공한다고 판단하지 않는다.

## 2. 아키스케치: DXF 및 3D 파일 내보내기 확인

공식 내보내기 문서: https://docs.channel.io/archisketch/ko/articles/2D3D-%EB%82%B4%EB%B3%B4%EB%82%B4%EA%B8%B0-f6594b7c

공식 사용 예시: https://www.archisketch.com/ko/blog/66b586337688f900193c2b0e

가격·기업 연동 안내: https://www.archisketch.com/ko/pricing

확인 사항:

- 프로젝트 공간을 DXF로 저장한다. 벽, 창문, 문, 기둥 및 단순 블록 형태의 가구가 포함된다.
- 3D 출력 형식은 FBX, glTF 2.0(GLB), SKP이다. 별도 3D CAD DWG 출력은 지원하지 않는다고 안내한다.
- 내보내기 문서는 일부 기업 고객 대상 유료 기능이라고 명시한다. 가격 페이지의 플랜 표시만으로 원하는 내보내기 권한이 보장된다고 해석하지 않는다.
- 공식 사용 예시에서 주소·아파트 검색과 평형·타입 선택 기능을 확인했다.

미확인 사항: 라이브러리에서 검색한 기존 아파트 도면을 위 형식으로 반출할 수 있는 범위, 일괄 다운로드/API 형상 제공, 자체 서비스에서의 저장·변환·배포 조건, 서울·경기도의 단지·타입별 실제 커버리지. 계정 로그인이나 유료 구매를 통한 출력 테스트는 하지 않았다.

## 3. SH 공개 첨부: 실제 DWG 확보

출처: https://www.i-sh.co.kr/houseinfo/

기존 로컬 SH 수집 목록의 파일명 링크를 조사하여 다음 DWG를 발견했다. 전체 SH 공개 파일 및 모든 ZIP 내부를 전수 조사한 결과는 아니다.

- 단지: 래미안신반포 리오센트, SH ID 70419. 이름은 기존 complex-70419.json과 대조했다.
- 원본 파일명: `20221025180309773_1159_59, 48.dwg`
- 직접 URL: https://www.i-sh.co.kr/houseinfo//upload//lease/20221025180309773_1159_59,%2048.dwg
- 저장 파일: `../verification/cad-sources/70419-6dedf6fcd83a.dwg`
- 출처·검증 기록: `../verification/cad-sources/70419-6dedf6fcd83a.dwg.json`
- 크기: 2,021,556 bytes. 다운로드 HTTP 200, DWG 헤더 `AC1018` 확인.
- SHA-256: `6dedf6fcd83a5869893aa2fec1b0fda5ef78b77a080cba7e99e96081d8b1d1a1`

검증 한계: DWG 내부 엔티티, 레이어, 단위, 치수, 평형별 실제 포함 여부는 아직 열어 보지 않았다. 파일명의 59·48만으로 두 타입의 완전한 도면을 확보했다고 판단하지 않는다. CAD 확보가 동·호별 배치, 높이, 창호 높이까지 확보했다는 뜻도 아니다.

## 공급 적합성을 확정할 때 필요한 자료

1. 서울·경기도의 단지명·주소·평형·타입·기본형/확장형 목록과 누락 목록.
2. 실제 납품 형식 샘플: DXF 또는 벽·문·창 좌표와 단위가 포함된 JSON. GLB만 제공한다면 개구부와 요소별 구분이 보존되는지 확인.
3. 자체 엔진에서 파싱·변환·저장하고 서비스할 수 있는 공급 조건. 뷰어 삽입만 가능한 계약인지 구분.
4. 일괄 제공 또는 API 호출 방식, 비용, 갱신 주기.
5. 경희궁자이 등 이미 검증한 타입을 포함한 소수 샘플의 치수·벽·창 위치 비교.

이번 조사에서는 업체 연락, 계약, 결제 또는 새로운 대량 수집을 수행하지 않았다.
