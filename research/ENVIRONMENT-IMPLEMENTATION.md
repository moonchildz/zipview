# 주변 환경 구현 기준

사용자 확인: 2026-09-17. 이후 환경 구현 작업은 이 우선순위와 검증된 시험 흐름을 이어간다.

## 고정 수집 원칙 (2026-09-18 사용자 지시)

- 수치지도는 **무조건 1:1,000**만 사용한다. 다른 축척으로 자동 대체하거나 혼합하지 않는다. 미제공 지역은 미확보로 기록한다.
- **경기도 전역은 필수 대상이며 서울 다음, 부산보다 우선**한다(2026-09-19). 일부 아파트 주변으로 한정하지 않는다.
- 현재 서울 위성 다운로드는 마저 진행한다. 이후 전국 수치지도·지리 데이터 수집과 검증을 먼저 수행하고, 나머지 위성 영상 획득은 가장 마지막 단계로 미룬다.

## 주요 구현 대상

1. 건물
2. 나무·숲 수관
3. 낮은 식생
4. 도로·단지 내부 길

강·하천·호수 등 물 영역을 별도 대상으로 추가한다. 양재천·한강에서 물 후보를 지형 위에 표시하는 시험까지 진행했다. 오분류·누락과 수위 검증이 남아 있으므로 완성된 물 복원으로 취급하지 않는다.

## 현재 채택한 처리 순서

1. 위성 영상과 수치지도를 같은 좌표계에 배치한다. 현재 시험은 카탈로그 경계와 0.5m GSD를 사용한 잠정 정합이다. 실제 기준점 오차 검증과 별개다.
2. 수치지도 등고선·표고점으로 지형을 보간한다. 건물 외곽과 식생은 같은 지표면을 기준으로 배치한다.
3. SegFormer로 수관 및 낮은 식생 후보를 얻는다. 수관 확률 기준 0.5, 낮은 식생은 rangeland가 최댓값이면서 0.35 이상을 기본 시험값으로 사용한다. 0.5 비교도 유지한다. 중복 시 수관을 우선한다.
4. 수치지도 도로경계 면과 OSM 내부 길 중심선에 폭을 적용한 면을 합친다. OSM 실제 width 태그가 있으면 우선하며 없으면 명시된 추정 폭을 사용한다. 교량·터널·다른 높이의 길은 지상 제외 마스크로 쓰지 않는다.
5. **도로·길 면을 나무 수관과 낮은 식생 양쪽에서 제거한 뒤 3D를 생성한다.** 원본 예측과 도로 제외 결과는 따로 보존한다. 도로 위 실제 수관도 잘리는 표현 규칙이다.
6. 나무·숲은 남은 수관 영역 안에서 기존 절차적 수목 모델을 생성한다. 낮은 식생은 남은 영역 안에서 낮은 3D 덩어리로 표현한다. 나무 기본 약 8m, 낮은 식생 0.4m는 표시용 가정이며 실측 높이·수량·수종이 아니다.
7. 도로와 식생 마스크의 비중첩, 낮은 식생 모델 경계, 지형 높이 및 화면 동작을 검증한다. 원본/후보/도로 제외 결과를 비교할 수 있게 한다.

## 정확도와 미완료 부분

- 건물은 현재 결합 시험에서 수치지도 외곽선으로만 표시한다. 완성된 건물 3D나 실제 세대 전망과 구분한다.
- 낮은 식생은 잔디·관목·꽃·화단을 세부 분류한 결과가 아니다. 그림자·지붕 오분류가 남는다.
- OSM에 없는 길, 추정 폭, 지도·촬영 시점 차이와 위치 오차가 남을 수 있다.
- 등고선 보간은 옹벽·수직 단차를 그대로 복원하지 않는다.
- 촬영 시기와 그림자를 비교해 영상 선택을 보완한다. 이미지 생성으로 실제 관측의 빈 부분을 확정하지 않는다.
- 양재천·한강 시험은 물 클래스가 최댓값이면서 확률 0.5 이상인 후보를 표시한다. 물 후보는 수관·낮은 식생에서 제거한다. 도로와 물의 중복 및 교량 높이는 별도 검증이 필요하다. 수면은 지형에 얹은 표시이며 실측 수위·수심이 아니다.
