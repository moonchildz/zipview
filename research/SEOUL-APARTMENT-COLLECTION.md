# 서울 아파트 정보 수집

서울시 공동주택 목록(OA-15818)을 입력으로 삼아 아파트·주상복합 계열 전체를 순회한다. 2026-09-13 갱신 목록은 2,888건이며 수집 대상은 2,834건이다. 연립·다세대 등 범위 밖 또는 분류 미확인 54건도 제외 사유와 함께 보존한다. 이 목록에 없는 소규모 아파트까지 서울 전체 건물을 빠짐없이 열거했다는 뜻은 아니다.

현재 자동 수집 출처는 KB 공개 검색·단지 페이지·동호수 응답이다. 단지명, 주소, 좌표, 세대수, 동 목록, 평형별 전용/공급면적, 기본/확장 평면 이미지, 공급자 면적 ID에 따른 동호수 연결을 저장한다. 단지배치도, 기준층 도면, 창의 지리적 배치와 정확한 층고 수집까지 완료하는 명령은 아니다. 공개 페이지에 표시된 외부 평면도 링크도 후속 수집 근거로 보존한다.

```powershell
npm.cmd run collect:seoul-apartments
npm.cmd run collect:seoul-apartments -- --status
```

기본 외부 요청 간격은 1초이며 한 단지씩 처리한다. 실행 중에는 같은 수집기를 중복 실행하지 않는다. `--status`는 실행 중에도 파일을 읽기만 하므로 사용할 수 있다. 상태 파일은 `research/linkage/generated/seoul-apartment-collection.json`, 작은 집계 파일은 같은 이름의 `.summary.json`이다.

단지마다 상태를 저장하고 50개마다 공통 검색 인덱스를 갱신한다. 중단 후 같은 명령으로 실행하면 대기 목록부터 계속한다. 실행 중이던 한 단지는 요청 캐시를 이용해 재개한다. 이미 완료된 목록을 처음부터 다시 수집하지 않는다. 실행 상한은 기본 외부 요청 150,000회이며 `--max-requests`로 조정할 수 있다. `--limit 10`은 단지 10개를 처리하고 멈추는 시험 실행이다.

HTTP 403/429가 반환되면 해당 실행의 모든 추가 외부 요청을 중단하며 우회하거나 자동 재시도하지 않는다. 사용자가 중지하려면 Ctrl+C를 누르거나 상태 파일 경로 뒤에 `.stop`을 붙인 빈 파일을 만든다. 이후 재개하려면 해당 중지 파일을 제거한다. 종료된 수집기의 오래된 잠금 파일은 PID 생존 여부 확인 후 자동 정리한다.

상태 구분:

- `pending` / `running`: 대기 / 처리 중.
- `collected`: 현재 공급자에서 모든 타입에 이미지가 있고, 모든 세대가 이미지 있는 타입에 연결되며 공급자와 서울시 세대수도 일치. 실제 공간 배치 완료를 뜻하지 않는다.
- `partial`: 이미지가 있으나 일부 타입·호수·세대수 대조가 미완료.
- `no-plans`: 현재 공급자에서 이미지 미확보. 다른 출처에도 도면이 없다는 의미가 아니다.
- `not-found` / `review` / `failed`: 검색 실패 / 단지 식별·주소 확인 필요 / 수집 오류.

같은 주소의 여러 단지 또는 주소가 다른 유일 검색 결과를 임의로 선택하지 않는다. 서울시 주소와 공급자 상세 주소가 일치해야 연결한다. 이미지와 원자료는 단지별 공급자 ID로 저장하며 도면 방향을 추측해 채우지 않는다. 전체 처리 종료와 전체 정보 확보 완료를 별도로 구분한다. 집계는 공급자 ID와 이미지 SHA-256을 중복 제거한다.

`--retry-incomplete`는 자료 보완 후 부분 수집·검색 실패·검토 대상의 재수집을 시도한다. 요청 캐시는 재사용하므로 같은 공개 응답에 없는 정보가 자동으로 생기지는 않는다. 갱신 시점이나 추가 출처 확보에 따라 다시 시도한다.

검증:

```powershell
node --test tests/address-pipeline.test.mjs tests/seoul-apartment-queue.test.mjs tests/linkage-pipeline.test.mjs
node scripts/build-linkage.mjs
```

자료 저장 위치:

- `research/seoul/raw/apartments.json`: 서울시 원본 목록.
- `research/linkage/providers/kb/`: 단지별 정규화 정보.
- `research/linkage/downloads/kb/`: 평면도 이미지.
- `research/linkage/cache/`: 요청별 캐시와 해시·수집 시각.
- `research/linkage/generated/catalog.json`: 앱 검색용 공통 인덱스.
