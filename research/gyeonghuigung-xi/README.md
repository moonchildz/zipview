# 경희궁자이 2단지 204동 201호 — 2026-09-10

실행: `/?site=xi`. 신촌푸르지오 화면은 `/`에서 유지한다.

## 창문 선택 업데이트

아래 기록은 초기 외벽 후보 검토 이력이다. 이후 [호수 배치 자료](unit-layout-research.md)를 확보하여 현재 화면은 1·2라인과 59A 참고 평면의 외부 창 5곳을 연결한 후보로 변경했다. 기존 오른쪽 끝 1m 지점은 더 이상 기본값이 아니다. `src/xi-unit-layout.js`에서 평면 좌표를 OSM 외벽에 투영하며 실제 창 위치 검증 상태는 계속 `false`다. 18층 부분 높이는 기존 65m를 층수 비율로 환산한 별도 렌더링 후보다. 실측 층고나 준공도면을 대체하지 않는다.

## 확인된 자료와 계산

- 사용자 지정 대상: 204동 201호. 201호의 존재·평면 타입·거실 창은 독립 검증되지 않았다.
- [OSM 단지](https://www.openstreetmap.org/way/359124892): 경희궁자이2단지아파트, 송월길 99.
- [OSM 204동](https://www.openstreetmap.org/way/608374570): 21층, 높이 태그 65m. 건축물대장 실측 높이로 취급하지 않는다.
- 단지 폴리곤과 204동 이름·위치를 대조했다. 원본은 `osm.xml`이며 [OSM Map API](https://www.openstreetmap.org/api/0.6/map?bbox=126.961,37.568,126.968,37.574)로 수집했다.
- Google 인증 조회는 단지 대표 POINT를 반환했다. 개별 동 외곽선은 얻지 못했고 Google 좌표로 모델을 보정하지 않았다.
- 기존 OSM 스냅샷에 새 영역의 건물·도로를 ID로 병합했다. 주변 수집 범위와 시점은 균일하지 않다.
- 새 중심은 204동 외곽선의 닫힘 중복점을 뺀 꼭짓점 평균이다.
- 8m 이상 외벽에서 건물 바깥 법선을 계산하고, 단지 경계 꼭짓점 평균을 향하는 법선 내적이 가장 큰 외벽을 기본 후보로 선택했다. 외벽 중점의 바깥 0.8m에 카메라를 놓았다.
- 기본 후보 방위 약 138.84도, 위도 37.57049578 / 경도 126.96294902. **201호 창문으로 확인된 좌표가 아니다.** 다른 계산된 외벽 후보도 화면에서 선택 가능하다.
- 2층과 7층 비교 시나리오: 지형 표고 + (층−1)×가정 층고 2.9m + 눈높이 1.5m. 7층 비교는 사용자 세대 요청과 별도의 비교용 가정이다.

## 정확도 제한

### 방향 재검토

- 외곽선 원본 위경도를 `pyproj.Geod(WGS84)`로 독립 계산했다. 남동쪽 외벽의 접선은 진북 기준 48.96395°, 바깥 수직 방향은 **138.96395°**다. 앱의 국소 평면 좌표 계산 138.84409°와 차이는 0.11986°로, 화면 표시로는 둘 다 **139°**다. 모델과 카메라의 좌표 일치를 위해 앱 각도는 유지한다. 이 소수점 자릿수는 측량 정확도를 의미하지 않는다.
- 남서쪽 외벽은 WGS84 기준 228.72278°, 앱 기준 228.84280°다. 북동쪽 49°는 남동쪽 외벽에 수직인 측면 후보이며 같은 거실 방향이 아니다.
- [해드림 중개사 게시 매물](https://town.aipartner.com/realtor/20840)은 204동 59A를 남동향 정원뷰, 84E를 남서향으로 기재한다. [다른 중개사 매물](https://town.aipartner.com/realtor/45090)에서도 204동 59A 남동향을 확인했다. 이는 호수까지 특정하는 자료는 아니다.
- [급매캐치 후기 집계](https://www.geummaecatch.com/complex/109379/review)는 204·205동 25평의 1·2호 라인이 단지 안쪽 정원 방향이라는 블로그 내용을 재인용한다. 원문 링크와 동호 배치 도면을 확보하지 못해 간접 근거로만 사용한다.
- 결론: **201호는 남동향 약 139°로 추정**, 기존 기본 방향을 유지한다. 1·2호의 좌우 순서와 거실 창 좌표는 미확정이므로 외벽 중점을 실제 201호 창 위치라고 표시하지 않는다. 201호 타입도 확정값으로 입력하지 않는다.
- 재현: `node scripts/prepare-xi.mjs` 실행 후 `.tools/mapinfo-python/Scripts/python.exe scripts/check-xi-direction.py`. 결과는 `direction-check.json`.

- `mapinfo`의 북아현동 6개 도엽은 204동 위치를 포함하지 않는다. 신촌푸르지오용 수치지도 보정을 재사용하지 않았다.
- 지반 추정 약 49.28m는 기존 Mapzen 지형을 새 중심에 재표본화한 값이다. 고해상도 실측값, 실제 1층 바닥 표고 또는 단지 조경 데크 높이가 아니다.
- 시점의 예상 눈높이 표고는 약 53.68m(2층), 68.18m(7층). 층고·1층 바닥 표고 미확정으로 실제 조망을 보장하지 않는다.
- 옹벽·수목·창틀·지하주차장 위 인공지반은 미반영이다. 2층 전망에서는 특히 큰 영향을 줄 수 있다.
- [59A/B/C 평면도 게시글](https://study-memo1.tistory.com/entry/경희궁자이-2단지-17평형24평형-A-B-C-소평형수-평면도)에서 59A 기본형 참고 이미지를 확보했으나 201호와 연결할 근거가 없어 세대 도면으로 사용하지 않았다.
- 201호 타입을 임의로 정하거나 신촌푸르지오 실내 모델을 재사용하지 않았다. 평면도·실내 3D 탭은 이 세대에서 비활성화한다.

## 재현

### 거실 창 후보와 시야각 조정

- 사용자 확인으로 남동향 방향을 유지한다. `src/xi-window.js`는 남동 외벽 길이 20.309m에 59A 두 세대가 나란히 배치됐다고 가정한다. 참고 확장형 평면의 전면 폭은 3.510+3.800+3.215=10.525m, 거실 창 중심은 한쪽 끝에서 5.410m다. 외벽 절반에 비례 축소해 두 창 중심 후보를 계산한다. OSM 외곽선과 평면의 일치가 검증된 것은 아니다.
- 후보는 외벽 남서 끝에서 약 5.22m / 15.09m, 서로 약 9.87m 떨어진다. 두 세대가 거울상이라는 가정이며 평면 반전 여부에 따른 추가 이동은 약 0.28m다. 이 값은 전체 오차 한계가 아니다. 201호의 좌우 배치 근거가 없어 기본값을 **남서쪽 세대 후보**라고 명시하고 북동쪽 후보 및 이전 중점과 비교할 수 있게 했다.
- 카메라는 외벽 바깥 0.2m의 창 앞 시점이다. 건물 내부는 채워진 입체여서 실내 관찰점으로 이동시키지 않는다. 창틀/벽 두께/실내 후퇴 거리와 창의 개구부 제한은 아직 반영되지 않았다. 기존 외벽 중점 바깥 0.8m와 구분한다.
- Xi 화면은 기존 세로 65° 고정에서 **가로 50° 고정**으로 변경했다. 각 비교 화면의 실제 종횡비로 세로 FOV를 다시 계산하므로 화면 크기가 바뀌어도 가로 광각이 확대되지 않는다. 조절 범위 35–75°, 초기 시선은 수평(기존 아래로 4°), 초기화에도 적용한다. [Three.js 카메라 문서](https://threejs.org/docs/pages/PerspectiveCamera.html)의 FOV는 세로 값이다.
- 가로 50°를 인간 전체 시야각과 동일하다고 간주하지 않는다. 평면 화면에서 눈에 보이는 크기를 맞추는 가로 각도는 `2*atan(화면의 실제 가로 길이/(2*눈과 화면 거리))`이며, 여기서 화면은 두 비교 영상 각각이다. 화면 물리 크기와 거리를 알 수 없어 50°는 왜곡을 줄이는 기본값이다.

검증: 테스트 27개와 빌드 통과. 1440px/390px 화면에서 204동 선택, 2층/7층 눈높이,
외벽 후보 전환, 층 변경, 가로 넘침 및 페이지 오류를 확인했다. 기존 신촌 화면도 다시 로딩했다.
