# 동·호와 평면 연결 후보

204동 1·2라인(2~18층), 205동 1·2라인(2~21층)은 59A, 211동 1·2라인(2~15층)은 84A로 연결한다. 총 102개 조합이며, 현재 세대 대장에 따른 존재 확인이 아니라 배치도에서 읽은 타입·층 범위의 후보다. 1층 예외는 제외했다. 211동 7라인은 확보한 배치도에 없다.

- 동호수 배치도: https://www.r1472.co.kr/_file/Group/21506081506430596_042.jpg
- 타입 배치도: https://s3.ap-northeast-2.amazonaws.com/zippoom-blueprint/1c0611ad-1ccd-488b-aa26-70017fdeee9a%EA%B2%BD%ED%9D%AC%EA%B6%81%EC%9E%90%EC%9D%B4.webp
- 84A 평면 출처: https://w2althy.tistory.com/15598549 (2018-09-10)
- 84A 면적 참고: https://fin.land.naver.com/articles/2531096231 (211동 매물 참고, 특정 호수의 증명 아님)

84A는 이미지 하단 확장형을 사용하고 가로 치수 3810+5000+3515=12325mm로 창 폭을 환산했다. 내부 벽과 창 위치는 이미지 판독 초안이다. 방향과 반전은 현관·공용 코어 상대 위치에서 추론한 후보이며 독립 정합 검증은 미완료다. 세대 바닥 표고·층고·준공 변경도 미검증이다.

전체 자료의 일괄 연결은 `npm run build:linkage`로 재생성한다. 새로운 세대마다 이 문서나 UI 코드를 수정하는 구조가 아니라 단지별 입력 어댑터와 JSON 범위 자료에서 공통 인덱스를 만든다.
