## 새로 연결한 공식 동호수 원본

이미 보유하던 전국 공동주택 공시가격 CSV **15,580,435행 전체**를 읽고 기존 기대 행 수와 SHA-256을 검증했다. 원본은 수정하지 않았다.

- 현재 KB·SH 주소 목록에 해당하는 **1,266,682개 원본 행**을 저장했다.
- 연결된 출처 기록은 5,037개이며, 이 중 **KB 단지 기록은 1,866개**다. KB·SH가 같은 장소를 가리킬 수 있으므로 5,037을 고유 단지 수로 해석하면 안 된다.
- 확보된 지번과 충돌하는 연결 15,266건을 제외했다. 지번을 모르는 경우는 도로명주소 후보로 남겼다.
- 공식 동호수와 기존 KB 동·호·전용면적이 일치하는 연결은 933,268건이다. 이 중 평면도 이미지 파일까지 존재하는 연결은 **426,416건**이다. 단지 간 중복 가능성이 있는 연결 수이며, 모델 완성 가능 세대 수가 아니다.
- 면적만 같은 후보, 반올림 면적 후보, 동일 면적의 복수 타입, 기존 동호수 자료의 충돌을 구분했다. 기존 앱의 타입 할당은 변경하지 않았다.
- 2025년 원본이므로 신축·재건축·분할 등 현재 현황과의 차이는 별도 검토 대상이다.

## 공간 자료

좌표가 있는 **6,104개 출처 기록**에 대해 주변 자료를 대조했다. KB·SH 간 중복을 제거한 단지 수는 아니다.

| 1:1,000 건물 지도 경계상자 중첩 | 6,103 |
| 1:1,000 등고선/표고점 경계상자 중첩 | 6,103 |
| 다운로드 RGB 영상의 반경 400m 카탈로그 영역 | 5,513 |

지도 ZIP, RGB 파일 경로, OSM 객체 ID를 보존했다. 이 판정은 건물 높이 속성·실제 영상 유효화소·전 조망 범위·단지 내 모든 길의 완비를 뜻하지 않는다. 다른 축척 지도는 사용하지 않았다.

## 잘못 확정하지 않도록 구분한 것

- 이름만 같고 여러 주소에서 쓰이거나 공고 지역이 다른 이름 연결 14,095건을 약한 근거로 분리했다. 도로명주소와 지번으로 읽은 공식 세대 자료는 일반 텍스트 이름 검색과 별도로 연결했다.
- SH의 타입 이미지 중 자료명이 실내 사진을 가리키는 8건을 평면도 후보에서 분리했다. 나머지 이미지의 실제 내용까지 모두 판독한 것은 아니다.
- 텍스트가 나오지 않은 파일 866개 중 PDF 841개에 OCR 필요 표시가 있다. 구형 Office 38개, CAD 내부 구조 1개, 파서 오류 3개 등은 추가 검토 목록으로 남겼다.
- 압축 내부 내용 일부를 미룬 파일 2개와 XML 추출 텍스트 제한에 걸린 파일 7개를 표시했다. 전국 공시가격의 대용량 CSV는 별도 스트리밍 절차로 전체 검증·연결했다.
- 모든 필요한 자료가 완비된 단지 수는 이 연결 수에서 자동 산출하지 않았다. 특히 배치 자료의 실제 수록 범위와 도면 내용은 파일명·키워드만으로 확정하지 않는다.

## 검증

- SQLite 무결성 검사 통과.
- 첨부파일·단지·문서 연결 대상 누락 0건, KB 타입 ID 참조 오류 0건.
- 기존 공식 동호수 원본을 그대로 보존: 경희궁자이 1,148행, 신촌푸르지오 777행, 한신한진 3,929행 모두 유지.
- PDF 페이지 위치, 압축 내부 경로, HWPX 본문, 동일 면적 타입의 모호성·충돌 등 7개 테스트 통과.
- 브라우저에서 검색, 단지 상세, 원본 열기, 공식 세대 조회를 확인했다.
