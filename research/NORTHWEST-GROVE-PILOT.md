# 서울 서북부 위성·수치지도·수관 결합 시험

2026-09-17 업데이트: 아래는 최초 평면 시험 기록이다. 현재 화면에는 수치지도 등고선·표고점 지형을 연결했고 경희궁자이 구역도 추가했다. 최신 실행 절차와 한계는 [지형 결합 기록](GROVE-TERRAIN-PILOT.md)을 따른다.

## 결과

`northwest-grove.html`에서 2024-06-06 서북부 장면 `C1_20240606014634_17816_00340169`의 월드컵경기장·문화비축기지 주변 약 1,024m 정사각형을 비교한다. 전체 서북부 장면을 처리한 결과가 아니다.

- 기존 `north-sports-2024` RGB/SegFormer 마스크의 중앙 2048×2048픽셀을 재사용했다. 수관 확률 기준은 0.5다.
- 수관 206영역(64픽셀 미만 영역 제외), 수치지도 9개 도엽에서 건물 외곽 619개를 추출했다.
- `src/aerial-grove.js`의 기존 숲 표현을 재사용했다. 기본 설정의 2,079개 배치는 실제 나무 수가 아니다. 높이 8m를 기준으로 변화시킨 표현이며 4/8/12m 설정을 비교할 수 있다.
- 사진, 수치지도 건물 외곽, 수목 각각 표시 전환 가능. 수직 비교 및 사선 보기 제공.

## 좌표 근거 및 제한

TIFF 자체에는 GeoTIFF 좌표 태그가 없다. 카탈로그 장면 모서리를 EPSG:5179로 변환하면 거의 축에 정렬된 직사각형이 된다. 해당 범위를 실제 31659×29577픽셀로 나누면 0.499986m/0.499983m이며 XML의 GSD 0.5m와 일치한다. 이를 초기 픽셀→지도 변환으로 사용했다. 수치지도 PRJ에서 EPSG:5179로 변환한 건물 외곽을 겹쳤다.

경기장·문화비축기지·주변 아파트를 눈으로 대조했을 때 대체로 일치한다. 독립 기준점 잔차를 측정하지 않았으며 정밀 정합 완료로 간주하지 않는다. 높은 건물의 지붕과 지도상의 바닥 외곽은 다를 수 있다. 지형은 평면이며 건물은 외곽선만 표시한다. 실제 창문 전망/가림 계산에 연결하지 않았다. 다음 단계는 독립 지상 기준점 검증과 등고선 기반 지형 연결이다.

## 재생성·확인

```powershell
.tools/aerial-python/Scripts/python.exe scripts/prepare-northwest-grove.py
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5176 --strictPort
node tests/northwest-grove-browser.mjs
node --test tests/aerial-grove.test.mjs
```

준비 스크립트에는 기존 식생 패키지 외 pyproj 3.8.0, pyshp 3.1.6이 필요하다. 산출물과 지도 ZIP SHA-256/좌표 정보는 `verification/northwest-grove/scene.json`에 보관한다. `registration.jpg`는 원본 사진에 건물 외곽을 겹친 이미지다.

검증: 기존 수관 경계·구멍 내부 비침범 테스트 3개 통과. 신규 브라우저 검증에서 데이터 로딩, 지도/사진/수목 전환, 높이 변경, 수직/사선 보기, 데스크톱/모바일 확인 및 페이지 오류 없음. `oblique.png`, `top.png`, `mobile.png`에 화면 기록. 지역명은 경기장 및 문화비축기지 형상과 후보 좌표를 대조한 육안 판단이다.
